# 🎵 Spotify MCP Agent

Servidor MCP que integra com Spotify usando LangGraph.

## ✨ Ferramentas

🔍 **buscar_musica** - Buscar músicas  
👤 **buscar_artista** - Buscar artistas  
⭐ **top_musicas_artista** - Top músicas de um artista  
🎯 **recomendacoes** - Recomendações personalizadas  
📊 **analise_musica** - Análise técnica de uma música  

## 🚀 Setup (Grátis!)

### 1. Criar credenciais no Spotify

1. Vá a: https://developer.spotify.com/dashboard
2. Clique em "Create an App"
3. Preencha o formulário
4. Copie: Client ID e Client Secret
5. Cole no arquivo `.env`

### 2. Instalar dependências

```bash
pip install -r requirements.txt
```
